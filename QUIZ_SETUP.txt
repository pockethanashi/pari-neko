猫好きクイズ Ver.1 セットアップ
=================================

機能:
・3択クイズ
・登録問題から最大10問をランダム出題
・回答後、その場で正誤と解説を表示
・最終結果で点数、正解率、称号を表示
・問題はGoogleスプレッドシート管理
・カテゴリ、難易度に対応
・publishedで公開/非公開を管理

---------------------------------
1. スプレッドシートに quiz シートを追加
---------------------------------

現在 episodes / stories を置いているGoogleスプレッドシートに、
新しいシートを追加して名前を

quiz

にしてください。

1行目:

id
question
choiceA
choiceB
choiceC
answer
explanation
category
difficulty
published

quiz-template.csv を読み込んでもOKです。

---------------------------------
2. 各列
---------------------------------

id:
問題番号。1,2,3...でOK。

question:
問題文。

choiceA / choiceB / choiceC:
3つの選択肢。

answer:
正解を A / B / C のいずれかで入力。

explanation:
回答後に表示する解説。

category:
例:
登場人物
エピソード
会話
マニア

difficulty:
easy / normal / hard
または 初級 / 中級 / 上級

published:
TRUE → 公開
FALSE → 非公開

---------------------------------
3. GitHubへ追加
---------------------------------

サイトのルートへ

quiz.html
quiz.css
quiz.js

を追加します。

config.js / data.js の変更は不要です。

quiz.js は現在の config.js に設定されている
SPREADSHEET_ID をそのまま使い、
quiz シートを直接読み込みます。

---------------------------------
4. ナビへ追加
---------------------------------

各ページの global-nav 内に

<a href="quiz.html">猫好きクイズ</a>

を追加してください。

---------------------------------
5. 出題数
---------------------------------

登録されている公開問題が10問以上:
毎回ランダム10問。

公開問題が10問未満:
公開中の全問題を出題。

---------------------------------
6. 称号
---------------------------------

全問正解:
もう四姉妹です

90%以上:
丸井家常連

70%以上:
三姉妹通

40%以上:
なかなかの猫好き

40%未満:
猫好き見習い

---------------------------------
補足
---------------------------------

初版では問題だけをランダム化し、
A/B/Cの選択肢の位置は固定しています。

そのため answer 列は A/B/C で簡単に管理できます。

将来的には:
・カテゴリ別挑戦
・初級/中級/上級コース
・今日の1問
・正答率集計
・ランキング
などを追加できます。
